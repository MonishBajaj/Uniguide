# Uniguide

A verified, source-linked course finder, requirements and deadline tool for students going abroad to study any course in any country.

Every fact shown to a student comes from Postgres with a source link, a verified date, an effective intake cycle and a coverage tier (Listed / Extracted / Verified). The LLM extracts and explains; it never generates a deadline, fee or requirement at runtime.

Development setup lands with the first feature branch.
